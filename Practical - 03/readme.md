# Practical - 03:
## Implementation of max-heap sort algorithm

## Overall Summary

This task implements the max-heap sort algorithm in Python. The script reads an array from user input, builds a max heap, and then sorts the array by repeatedly moving the maximum element to the end and restoring the heap.

## Conclusion

The implementation demonstrates an in-place heap sort with O(n log n) time complexity. It produces a sorted array in ascending order while using the heap data structure to efficiently select the next largest value.
